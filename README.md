# Web Development Project

A collection of web development projects and user interface design assignments.

## Projects Included
- **Doodle Jump Clone:** A simple implementation of the popular Doodle Jump game (`doodle.html`, `doodlejump.js`, `doodlejump.css`).
- **Calculator:** A web-based calculator application (`lcalculator.html`, `lcal.css`).
- **Login Page:** A mock login interface (`login.html`).
- **Passport:** A passport-related interface (`passport.html`).
- **Other Pages:** Includes various other assignments (`index.html`, `pm1.html`, `test.html`).

## Technologies Used
- HTML
- CSS
- JavaScript

## Setup
Simply open any of the HTML files in your browser to view the projects.
